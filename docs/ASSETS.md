# 素材登记

公开站点中的视觉素材必须可以追溯。新增图片时，请记录用途、生成或授权方式、源文件位置与优化策略；未经确认的网络图片不得直接进入 `public/`。页面合并后不再使用的素材仍保留历史登记，但必须明确标注当前状态，不能让旧资源说明暗示站点仍有对应的公开栏目。

## `public/anime/*.webp`

- **用途**：动画收藏馆 89 条已看作品的封面识别图。
- **资料来源**：每条记录先由站点所有者提供片名，再人工核对 Bangumi 动画条目；条目页、原封面 URL 与本地文件映射保存在 `content/anime-catalog.json`。
- **公开名称**：页面只显示该条目的一个正式作品名，不展示输入别名或匹配别名。
- **版权边界**：封面版权归各作品原始权利方所有；Bangumi 只作为公开资料索引，本站不声称拥有封面，也不把封面当作原创品牌素材。
- **交付优化**：同步脚本把封面统一转换为 `420 × 630`、质量 78 的 WebP；89 张合计约 4.3 MB，单卡默认懒加载。
- **维护方式**：新增条目先更新 `content/anime-source.json` 并核对 Bangumi subject ID，再运行 `npm run sync:anime`；Windows 受限网络可使用配套 PowerShell 包装脚本。

## `public/games/*.webp`

- **用途**：游戏收藏馆 146 条 Steam 作品中的 104 张封面识别图；缺少本地缓存封面的条目使用页面空态，不以不明来源图片补齐。
- **资料来源**：维护者主动运行 `npm run sync:games`，从本机 Steam 客户端 `appcache/librarycache` 读取已经存在的封面；公开产品名、App ID、封面映射与商店入口保存在 `content/games-catalog.json`。
- **隐私边界**：目录不保存 Steam 账号标识、具体游玩时长、最近上线、好友资料、会话或授权信息，也不以时长生成评分或排名。
- **版权边界**：游戏名称和封面版权归各作品权利方所有；Steam 只作为客户端缓存与公开商店入口，本站不声称拥有这些素材。
- **交付优化**：同步脚本把可用封面统一转换为 `420 × 630`、质量 78 的 WebP；卡片默认懒加载，避免一次加载全部资源。
- **维护方式**：脚本可自动探测 Windows/macOS 常见 Steam 路径；非默认安装运行 `npm run sync:games -- --steam-dir <Steam 目录>` 或设置 `STEAM_DIR`。同步前必须确认只有一份目标用户缓存，生成后核对条目数、封面数与隐私字段契约。
